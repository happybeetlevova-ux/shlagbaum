# Шлагбаум

Android-виджет: открыть шлагбаум одним нажатием — приложение звонит на номер шлагбаума.

- До 3 кнопок, у каждой своё название, номер, цвет и значок (Двор, Парковка, Школа, Работа, Шлагбаум)
- Два вида виджета: в ряд и столбиком
- Номера хранятся только на телефоне

**Скачать:** [Shlagbaum.apk](https://github.com/happybeetlevova-ux/shlagbaum/releases/download/latest/Shlagbaum.apk)

APK собирается автоматически в GitHub Actions и подписывается ключом из секретов репозитория (`KEYSTORE_B64`, `KEYSTORE_PASS`).
